# Liver Disease Classification 🩺

## 📌 Project Overview
This project focuses on building a **machine learning model** to classify whether a patient has liver disease based on medical attributes.  
The goal is to assist in **early detection** of liver-related conditions using data-driven approaches.

---

## 📊 Dataset
- The dataset contains patient medical records such as:
  - Age
  - Gender
  - Total Bilirubin
  - Direct Bilirubin
  - Alkaline Phosphotase
  - Alamine Aminotransferase (ALT)
  - Aspartate Aminotransferase (AST)
  - Total Proteins
  - Albumin
  - Albumin and Globulin Ratio
- Target variable: **Liver Disease (Yes / No)**

> Dataset was preprocessed to handle missing values and ensure model readiness.
